HE ARCHIVE — 레이아웃 초안

1. 압축을 풀고 모든 HTML 파일, style.css, app.js, projects.js를 GitHub 저장소 main 루트에 업로드합니다. 기존 index.html과 projects.js는 교체합니다.
2. GitHub Pages 배포 후 사이트를 확인합니다.
3. index.html을 브라우저에서 열면 로컬 미리보기가 가능합니다.
4. 이미지 등록: 저장소 images 폴더에 파일을 올리고 projects.js의 heroImage, categories의 image, projects의 thumbnail 및 images 배열에 상대 경로를 입력합니다.
5. 작업물 수정: projects.js에서 title, description, category, images 등을 수정합니다. id는 중복 없이 유지합니다. feature:true는 가로 대형 카드입니다.
6. 색상과 여백은 style.css에서 수정합니다. 공통 메뉴와 레이아웃은 app.js에서 수정합니다.
7. 공개용 이메일은 projects.js의 email에 직접 입력합니다.

PDF 원본이나 개인정보, 실제 작업 이미지, 영상은 포함하지 않았습니다. 외부 폰트는 인터넷 연결 시 로딩되며 연결이 없으면 시스템 폰트로 표시됩니다.
